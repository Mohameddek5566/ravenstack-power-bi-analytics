# RavenStack SaaS Analytics — Power BI

An end-to-end analytics project using five connected datasets for a simulated SaaS company with 500 customer accounts. The dashboard examines recurring revenue, customer churn, engagement and customer risk.

## My documented contribution

- Prepared and cleaned the project datasets.
- Built the Power BI data model and relationships.
- Supported the dashboard visuals and DAX measures.
- Helped translate findings into business recommendations.

## Key findings

- The analysis recorded a 22% churn rate.
- 78 active accounts were classified as high risk using a rule-based model.
- The work includes descriptive, diagnostic and predictive views, including a three-month MRR forecast.
